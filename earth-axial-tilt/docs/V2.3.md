# v2.3 — Mercury: a day is not a rotation

## Implemented experiment

`mercury-lab.html` follows **one and the same elapsed time** through a Kepler orbit
and uniform 3:2 spin. The user can pause, scrub 0–2 orbital cycles, choose latitude
and model meridian, compare native eccentricity with a circular counterfactual,
inspect the middle perihelion in a magnified time window, restore a bounded link,
and export a 721-sample time-series CSV. New rendering shares the exact sunlight
vectors with numerical readouts. It is an orthographic geometric sphere, not a
photographic terrain map or a new free-camera WebGL implementation.

The baseline meridian is defined to be at apparent noon at the first perihelion.
It is **not IAU longitude**. Latitude is relative to the positive spin pole.
No temperature, atmosphere, terrain, libration, relativity, spin capture evolution,
or actual dated ephemeris is supplied. Neither a rendered sphere nor a passing
regression is evidence of a Mars/Uranus/Mercury climate model.

- [NAIF PCK00011](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc):

  ecliptic obliquity 23.43928°, the reproducible `audits/planet/pole_convention.py`
  derives tilt0.03402197° and perihelion Ls49.24790603°. Tilt is rounded to0.034°.
  This is about2 arcminutes, **not2 degrees**. Positive spin about this pole is prograde.
- [Correia & Laskar, 2009](https://arxiv.org/abs/0901.1843) motivates the3:2
  resonance relative to orbital **mean** motion, not instantaneous orbital speed.

To make the resonance inspectable and exact, the teaching spin period is P×2/3,
not an independently rounded value from another epoch. The resulting mean solar
day is 2P. This deliberately omits PCK's libration terms and secular corrections.

## Reproducible mathematical contract

Let c=t/P, M=2πc. Solve E−e sinE=M on a bounded branch, then unwrap the true
anomaly ν continuously across two orbits. Seasonal longitude Ls=ν+Ls_peri.
The Sun's equatorial angle is α=unwrap atan2(cosε sinLs,cosLs).
Spin is θ=α(0)+3πc. The apparent body-fixed solar longitude is α−θ;
no modulo is applied to the plotted curve. θ makes3 full turns in2 orbits,
while α−θ changes by−360°.

The analytic instantaneous rates (degrees per Earth day) are:

```
meanMotion = 360/P
orbitRate = meanMotion*(1+e*cos(nu))^2/(1-e^2)^(3/2)
sunEquatorialRate = orbitRate*cos(epsilon)/(1-sin(epsilon)^2*sin(Ls)^2)
spinRate = 1.5*meanMotion
apparentRate = sunEquatorialRate - spinRate
```

Positive apparentRate identifies the reversal, not an inferred animation trick.
The zero-eccentricity counterfactual retains3:2 spin but removes reversal.
At model meridian90°, three geometric horizon crossings occur around the middle
perihelion. The magnified window0.9–1.1cycles samples401 points. The full curve
samples721 points over2orbits. Plots are bounded samples, not sunrise event solvers.

Instantaneous horizontal TOA flux is S max(0,n·s), with r in au and S=1361/r².
Geometric elevation is asin(n·s). A point Sun and no atmospheric refraction are
assumed. The frozen-orbit `illumination.daylightHours` returns **null** for Mercury;
its lit rotational fraction is not multiplied into an alleged real daytime duration.

## State, lifecycle, verification

`mercury=1` owns one strict JSON settings object (five fields; bounded numbers).
Unknown/duplicate keys, wrong versions, string numbers, nonfinite values, excessive
length, and malformed percent sequences fail atomically. URL creation strips query
and userinfo. Links never import playback. Display language and size are optional
local preferences, not scientific fields. Invalid drafts leave accepted results intact.
Animation uses bounded visible-tab time steps; hiding or leaving the page pauses it.

`tests/mercury.test.ts` compares604 cases to independent bisection/half-angle orbit
math, finite-differences the apparent angular rate, checks3:2closure, local
hour-angle irradiance, horizon crossings, circular non-reversal, and export/state.
`e2e/v23.spec.ts` checks actual rendering, controls, state, CSV and Japanese Large
390px with blocked storage in Chromium and WebKit. Same-HEAD run evidence is
recorded separately after completion. Existing Earth science modules remain untouched.
