# v0.5 — thermal response lab

## Scope

Temperature-model evolution only. Preserve v0.4 typography, location controls, spin/year separation, astronomical formulas and independent project structure. No deployment, repository visibility change, climate API, extra package dependency, or local Git reset is required.

## Added

- `physics/energyBalance.ts`: 90-band finite-volume seasonal EBM, conservative transport, half-day implicit integration, explicit convergence check, periodic temperature sampling.
- `physics/temperatureModel.ts`: one temperature source for UI, annual profiles and globe rows, strict configuration matching, explicit legacy mode, shared colour-scale limits.
- `physics/climate.worker.ts`: bounded six-entry cache, same-parameter Earth reference and honest error replies.
- `ui/thermalClient.ts`: one active/latest-request ownership; obsolete replies are ignored, explicit failure and retry path.
- Two readable controls: Temperature model (Thermal EBM / Illustrative), Heat storage (2.5 / 10 / 50 m equivalent).
- Ready/loading/error status, no stale temperature display, extra warning for large model extrapolations. Daylight and instantaneous/daily irradiance remain independent.
- Model/heat-storage provenance and warmest model date in annual-temperature summaries. Multiple near-equal maxima are not interpreted as a unique physical seasonal lag.

## Verification

The repository retains 39 existing unit tests and 17 browser tests. New suites add energy conservation, zero-tilt stationarity, convergence/periodicity, half-year symmetry, inertia/amplitude/phase, annual-mean invariance with heat capacity, high-obliquity redistribution, spatial/time refinement, no secret clipping, input rejection, source consistency and async request ownership.

Browser tests cover model-to-map/readout/graph agreement, exact legacy recovery, equal-tilt reference identity, thermal changes independent of astronomy and daily spin, Large text/mobile layout, rapid input, blocked-worker recovery and explicit extreme-model warnings. Existing browser readiness checks now wait for the initial thermal year, rather than treating an arbitrary non-dash loading label as a completed result.

The ChatGPT working environment has no package-network access. Numerical checks run compiled project TypeScript directly. A separate uncommitted preview harness is not a substitute for the real dependency tree or renderer. The final GitHub Actions run must pass before the release is reported verified; browser screenshots are stored as run artifacts.

## Limits

The equation, parameters, assumptions and limits are in SCIENCE.md. Neither model is a measured-city climate. Heat storage is uniform over the planet, and the returned cycle is an equilibrated year. Fixed albedo/linear OLR can extrapolate strongly at 90-degree tilt. Model values are not physical forecasts. The optional external Earth texture remains unchanged; package-lock / npm ci migration and real Safari-device testing are still separate work.
