# v1.4 — Earth Feedbacks Lab, alpha 1

## Shipped scope of this candidate

A production-built `feedback-lab.html`, linked from the main Earth laboratory,
implements a **90-band zonal** ice–albedo experiment. It is intentionally a
separate experiment workspace, not a hidden substitute for the real-geography
18×36 model. Main Earth Classic, idealized surfaces and real geography retain
their equations, profiles, schema 4 and numerical results. Two-dimensional
feedback and direct feedback colouring of the main 3D globe are not included
in this first milestone. The v1.4 track is not declared fully complete by this
alpha label.

Warm/cold seeds under identical forcing, feedback on/off, full-state continued
paths, a cooling/warming/cooling sweep, point/year temperature, a latitude/year
map (temperature or daily snow/ice proxy), diagnostics and portable settings
are implemented. Loading settings does not auto-run. A history stops at the
first unsettled stage; its last simulated year remains visible as **not an
equilibrium**. There is no numerical clipping or silent fallback.

## Scientific contract

- Inherit Classic's A=210, B=2, D=0.55, warm albedo
  `0.3 + 0.078 P2(sin(latitude))`, 365-day model orbit and geometry.
- Cold albedo 0.62 applies when the old-step temperature is **strictly below
  −10°C**. Equality is warm. The threshold is a teaching snow/ice coverage
  proxy, **not the physical freezing point of seawater**.
- Uniform +20°C and −60°C starts are specified teaching seeds. No annual-mean
  initial-guess substitution is permitted. History steps inherit the actual
  prior final day-1-phase array, not just a seed name or summary temperature.
- Half-day IMEX Euler: solar forcing at the step end, albedo from T_old,
  outgoing radiation and meridional diffusion implicit in T_new. Diagnostics
  use this identical RHS; recalculating albedo from T_new would test another
  discrete scheme. Periodicity requires all 730 temperature phases to agree
  below 1e-6°C **and** all threshold masks to repeat. The run is bounded at
  80 years; unsettled is distinct from a numerical error.
- Cold-area diagnostics are area weighted, not a count of grid cells.
  Annual proxy area uses half-step old-state masks. The map's proxy uses
  daily sampled temperatures; it is a daily display, not a resolved melt
  fraction. With feedback off the proxy is disabled, not physical proof of
  absent ice.
- No latent heat, ice mass/thickness, evaporation, topography, ocean currents
  or climate-cloud feedback. Extreme temperatures are explicit extrapolations.
  Visual clouds are not added or used as scientific input.
- Solar multiplier 0.7–1.5 is a sensitivity control, not reconstructed solar
  history. Discontinuous threshold transitions are timestep/grid sensitive.
  Teaching paths are reproducible experiments, not real tipping-point forecasts.

Sources checked 2026-09-27: Brian E. J. Rose,
[The Climate Laboratory — Ice-albedo feedback](https://brian-rose.github.io/ClimateLaboratoryBook/courseware/albedo-snowball/),
and the [climlab albedo source](https://climlab.readthedocs.io/en/latest/_modules/climlab/surface/albedo.html).
The equation and finite-volume implementation here are project implementations,
not execution of climlab or a claim of equivalence to its complete climate model.

## Runtime, reproducibility and memory

One dedicated Worker computes a complete comparison or path; obsolete work is
terminated. A 120-second absolute deadline is not extended by progress. Cancel
stays canceled until deliberate Run; scientific edits immediately discard visible
old results. Null, wrong-identity, malformed arrays, incorrect grid, invalid
summary/diagnostics and broken path-state continuity fail before acceptance.
All-year validation happens once at ingress, never per render.

No LRU or hidden second result cache. There is one accepted result containing
at most 17 daily fields, bounded to 6 MiB of retained ArrayBuffers; this is NOT
peak process/heap usage. Working buffers, browser structured-clone overhead and
rendered plots are additional. Results are transferred from the Worker.

The `earth-feedbacks` version-1 envelope identifies the pinned model and the
full initial history. Unknown versions/models/keys, oversized paths and invalid
values fail atomically. Main Earth schema 1–4 remains unchanged. Day/latitude
only resample; changes do not launch a new simulation. Back-forward-cache page
hides retain the live state; a real page exit releases timers/worker/listeners.

## Numerical checks for this actual implementation

Cloud execution of `src/feedback/model.ts` was independently compared to Python
with a separate Kepler bisection/insolation formula, geometry assembly and SciPy
banded direct solve. Six complete 365×90 arrays, **197,100 values**, agree within
**1.31e-12°C**, against a predeclared 1e-5°C criterion. Cases: ordinary warm/cold,
feedback-off warm/cold, and tilt90/e0.3/peri90 warm/cold. This is actual source
validation, not reuse of the earlier prototype's pass and not climate accuracy.

Reproduce with locked Node dependencies and Python NumPy/SciPy:

```sh
python audits/feedback/oracle.py --output /tmp/earth-feedback-audit
```

Generated arrays/results stay outside Git. The runner records SHA-256 hashes of
all executed TypeScript modules. No candidate-generated golden is adopted.
Unit tests additionally cover analytical zero-diffusion backward-Euler branches,
order preservation across the albedo jump, discrete energy balance, unchanged
Classic feedback-off equivalence, real path-state inheritance, bounded
nonconvergence, mask/phase conventions, malformed replies and lifetime guards.

At the default 23.44°/circular/10m conditions the implementation gives warm/cold
annual means about +11.9196°C/−40.3493°C. The path 1→0.9→1→1.4→1 returns to solar
multiplier 1 first cold, then warm. These are results of the declared teaching
model, not weather predictions.

Prior independent design refinement measured half→quarter→eighth-day maximum
changes of approximately 0.187→0.040°C (ordinary warm), 0.343→0.107°C (tilt60),
and 0.645→0.254°C (tilt90/e0.3 cold). That prototype evidence is not an error
bound for all production conditions; actual-source refinement remains a
separate validation item. A threshold model may not have a unique periodic state.
