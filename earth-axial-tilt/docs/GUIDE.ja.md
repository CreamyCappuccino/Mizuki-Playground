# 地球の傾きラボ — 日本語ガイド

最初に上の「Language / 言語」で日本語を選びます。文字が小さければ地点パネルの「文字の大きさ」をLargeへ。「道具の表示 → 基本だけ」は外観や詳しい瞬間値を隠すだけで、実験条件を変えません。「すべて」で戻せます。

## 季節を見てみる

「視点 → 公転を俯瞰」で、太陽と地球を一緒に見ます。傾きを現在の地球から45°、90°へ変え、夏至・冬至ボタンを押してみましょう。「一年を再生」なら連続して位置が変わります。

地球は移動しますが、地軸は宇宙空間で同じ方向を保ちます。公転面と軸・太陽の向きに注目してください。サイズと距離は見やすさのための比率で、実寸ではありません。

## 昼と夜を見てみる

台北 →「今の日射」→「この地点を正午に」→「この地点を見る」→「一日を再生」。地表が傾いた軸の周りを回ります。今の日射は変わりますが、日平均の日射や気温は変わりません。

「一日」のグラフはその日付を固定した日射曲線です。グラフを触ると太陽時を選べます。太陽時は時計の標準時ではなく、極などでは一意に決まらないため「未定義」と表示します。

## 自転と公転を同時に見る

「自転＋公転を再生」は一つのモデル時計で両方を進めます。×1では一日が10秒。×4／×12でも自転と公転の比率は同じです。季節を素早く一年分眺めたいときは、従来の「一年を再生」の方が速く進みます。

この365平均太陽日のモデルでは、宇宙空間に対して一年で366回自転します。日付を止める「一日」と、自転角を止める「一年」は、引き続き独立した実験として残っています。

## 二つの地球を比較する

「地球 A・B を比較」を開き、23.44°／90°を選びます。最初は傾きだけが違い、「軌道の実験室」ではA/Bの軌道も個別に変更できます。各世界の春の基準からの経過日数、場所、自転角、気温モデル、熱のためやすさ、視点、色の尺度は共通です。狭い画面では上下に並びます。「地球を広く見る」で操作パネルを隠し、両方を眺めることもできます。

表は **A、B、A−B** の順。日平均の日射・昼の長さ・推定気温を比べます。傾きと軌道条件をすべて同じにすれば差分は0です。片方の温度が計算待ち／失敗なら、差分を古い温度で埋めず「—」にします。日射と昼時間は使えます。

地点パネルの主な値はA。年間グラフの破線は比較中ならBです。一日のグラフはAだけを表示します。同じ自転角は、異なる傾きで同じ視太陽時を保証するものではありません。

二つの画面は別々の仮想世界です。一つの太陽系に地球を二つ置いた実験ではありません。

## 熱のためやすさを調べる

熱収支モデルで、速い応答 → 中間 → 遅い応答と変えて、年間気温の山の高さと時期を見比べます。これは地球全体の熱容量の設定で、その場所が海か陸かを判定しているわけではありません。

気温は日平均相当の緯度帯モデルです。最高気温・体感気温・実測の天気予報ではありません。変更後に表示するのは、新しい条件に落ち着いた繰り返す一年で、突然地軸を倒した直後の一年ではありません。

## 季節マップで地球全体を見る

季節マップは横が一年、縦が緯度。昼の長さ・日射・気温を切り替え、気になる場所を押して地球側の日付と緯度を選べます。縦スワイプはスクロールです。

Classicでは、A/B比較中でもこのマップはAを表示し、差分の相手はAと同じ軌道・蓄熱を使った23.44°です。Idealized Land/Oceanでは、Aと同じ傾き・軌道で反対の素材を差分相手にします。どちらもBとの差ではなく、画面にも注記を出します。白い破線は太陽直下点の緯度で、最も暑い場所の線ではありません。

## 困ったとき

各「？」は、意味→操作例→見どころ→読み取りの注意を説明します。通常はhoverで短い説明、クリック／タップで詳しい解説です。Escは上に開いている解説から閉じます。

任意の機能の読込に失敗した場合、明示された再読み込みボタンでページを再読込します。熱計算だけの失敗は再計算ボタンで回復できます。描画が重ければ画質を下げても数値は変わりません。

## 実験を再現する（v1.1）

左パネルの「実験と保存・共有」を開き、問いを選んで「この実験を準備」を押します。自動再生はしません。説明の観察ポイントを読んでから、一日・一年・同時再生を選べます。「直前の実験へ戻す」は一段階の切り戻しです。

「実験リンクをコピー」は現在の条件のスナップショットです。条件を変えた後は再度コピー。localhostのリンクでは他端末から自分のMacを開けないので、別環境では「設定ファイルを保存」→別のアプリで「設定ファイルを開く」を使います。気温の計算結果や画像ではなく、条件を保存します。

リンクを開いても言語・文字サイズ・画質は受け手の設定を維持し、再生は停止します。知らないバージョンや壊れた設定は適用しません。蓄熱の速い／遅い応答は同一地点で順番に比べるプリセットで、A/Bの別熱容量ではありません。


## 軌道の実験室（v1.2）

左側の「軌道の実験室」を開きます。離心率は円からどれだけ楕円になるか。「従来の円軌道」で離心率と二つの角度を0へ戻せます。「現在の地球に近い例」は離心率0.0167、近日点の太陽方向282.94°の参考例で、今日の天文暦ではありません。「夏に太陽へ近づく」「冬に太陽へ近づく」を切り替えたり、新しい三つの実験プリセットで比べてみましょう。

A/B比較では、変更する地球を選んでから入力します。「Aの軌道をBへコピー」は軌道だけをコピーし、傾きは変えません。近日点・遠日点へ移動すると、距離・速度・日射が一緒に変わります。離心率0.2なら距離は0.8／1.2 au、日射の比は2.25倍です。この欄の日射は太陽光に垂直な面が大気上端で受ける値で、日平均や地上の日射ではありません。

近日点の角度は、太陽が見える方向を表します。太陽から見た地球の方向とは180°違います。「太陽方向−地軸方位」が90°のときが北半球の夏の基準です。四季の基準日は軌道に応じて変わります。A/Bが共有するのは各世界の春の基準（80日目）からの経過時間で、同じ天文暦や同じ季節角度ではありません。

地軸の方位角は固定した方向を比較する操作で、何万年にもわたる歳差を再現するものではありません。円軌道には特別な近日点がなく、傾き0°の四季の印は便宜的な基準です。それでも楕円なら距離の変化によって日射は変わります。

軌道を変えると気温は一年全体を再計算します。計算待ちの欄へ以前の気温は流用しません。極端な設定で非常に高い／低い値が出る場合は、簡易モデルの外挿であり実際の天気や居住可能性の予測ではないと表示します。旧七つのプリセットとschema 1の保存データは、従来の円軌道のまま再現されます。

## 気候地理の対照実験（v1.3 alpha 1）

「気候地理」でIdealized LandまたはIdealized Oceanを選びます。どちらも同じ緯度・傾き・軌道・日射を使い、熱のためやすさだけが違います。Landは従来のFast 2.5 m相当、OceanはSlow 50 m相当とまったく同じ計算です。A/B比較を閉じている間は年間グラフの実線が選択中の素材、破線が反対の素材です。比較中の年間破線はBになります。季節マップの差分は常にLand/Oceanの組み合わせなので、振幅と季節の山の遅れを見比べられます。Idealized profileでは反対の素材が自動的に基準になるため、従来の23.44°年間基準checkboxは隠れます。

これは実在地球の地図ではありません。選んだ素材が模型世界の全体を覆い、海岸線・経度差・標高・海流・蒸発・氷の融解は計算しません。地球画像の色から海陸を判定していません。Classicへ戻るとFast/Mixed/Slowの世界全体ノブが再び有効になり、従来の数値がそのまま復元されます。IllustrativeではClassicだけを使います。

schema 3のリンク／設定ファイルはこのprofileを保存します。古いschema 1/2はClassicとして読み込み、壊れた組み合わせは途中まで適用せず全体を拒否します。
