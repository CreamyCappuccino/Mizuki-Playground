# 地球の傾きラボ — 日本語の使い方

ヘッダーの **Language / 言語 → 日本語** で切り替えます。選択は同じブラウザに保存されます。Englishへ戻しても、角度や日付はそのままです。

各項目の **？** は、マウスをかざすと短い説明、クリック／タップすると詳しい解説を開きます。解説は「こう動かしてみよう」「ここに注目」「読み取りの注意」に分かれています。閉じるボタンかEscで戻れます。

## まず三つの操作を区別する

ドラッグは観察するカメラだけを動かします。自転は「一日を再生」または自転のスライダー。一年の位置は「一年を再生」または日付のスライダー。カメラを回しても、その場所の天気や時刻が変わったわけではありません。

## 実験1：なぜ季節が変わる？

「視点 → 公転を俯瞰」を選び、「公転全体を収める」を押します。地軸の傾きを現在の地球から90°へ変え、春分・夏至・秋分・冬至を切り替えます。宇宙空間では軸の方向が固定されたまま地球が移動し、夏至側と冬至側でどちらの極が太陽を向くかが入れ替わります。

太陽・地球のサイズと距離は見やすさのための比率です。太陽の模様と光の広がりも装飾で、表面温度や太陽活動の計算ではありません。四季ボタンは北半球の名称で、円軌道モデルの正確な四分の一周期を選びます。実際の暦日とは異なります。

## 実験2：今日の昼と夜

台北を選び、「今の日射」「この地点を正午に」「この地点を見る」。一日のグラフへ切り替えて一日を再生します。太陽が沈むと瞬間の日射はゼロへ向かいますが、日平均の数値は変わりません。グラフを触るとその太陽時へ移動できます。

## 実験3：熱をためるとどうなる？

「熱収支モデル」と一年の気温グラフを選び、熱のためやすさを速い応答→中間→遅い応答へ変えます。日射は同じでも、気温の山の高さや現れる時期が変わります。水深相当は地球全体の熱容量で、台北の周りの海の深さではありません。

## 実験4：地球全体の一年

「季節マップ」で昼の長さを表示し、0°・現在の地球・90°を比較します。上が北、下が南、左から右へ一年です。「23.44°との差」では青が減少、淡色が変化なし、暖色が増加を示します。破線は太陽直下点の緯度で、最も暑い場所ではありません。

マップをタップすると地球側の日付と緯度も変わります。経度は維持します。縦スワイプはスクロールです。「選択した場所を地球で見る」で拡大表示へ戻れます。

## よく間違えやすい数値

| 表示 | 意味 |
|---|---|
| 今の日射 | 大気上端の水平面への瞬間のエネルギー流束（W/m²） |
| 日平均の日射 | 夜も含む一日の平均。同じ緯度なら同じ値 |
| 日平均気温（推定） | 日平均相当の簡易モデル。最高／最低／体感気温ではない |
| 太陽時 | 太陽基準の時刻。タイムゾーンの時計とは別 |
| 23.44°の比較 | 同じモデルで傾きだけを変えた基準。実測の平年値ではない |

大きな文字は「文字サイズ → 大きめ」。地球だけを見たいときは「地球を広く見る」、戻るときは「操作パネルを表示」。画質を下げても科学の計算は変わりません。
