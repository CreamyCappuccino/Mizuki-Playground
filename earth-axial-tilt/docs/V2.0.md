# v2.0 — Planet Lab Foundation

## Scope

v2.0 introduces a thin planet-generic architecture without moving or rewriting the accepted Earth v1.x solvers.

The new layer defines:

- `PlanetDefinition`
- `OrbitDefinition`
- `RotationDefinition`
- explicit `ClimateModelCapability`
- independent Planet Lab state with a versioned share URL
- a thin Earth adapter that translates the existing v1.x orbital convention into seasonal longitude `Ls`

Earth v1.x remains the numerical authority for the existing Earth workspaces. The adapter is tested against the untouched Earth orbit/daylight/declination functions.

## Boundary

A planet definition does **not** imply that a temperature model exists. Astronomy and climate capabilities are separate.

This is deliberate preparation for Mars and later planets. It prevents Earth thermal coefficients from becoming accidental defaults for every world.

## State

The Planet Lab uses its own bounded `planet=1` URL fragment. It does not replace or mutate Earth schema 1–4, `earth-feedbacks v1`, or `earth-synthesis v1`.

## Acceptance target

- generic Earth adapter agrees with the accepted Earth v1.x astronomy
- existing Earth sources are not moved
- no existing Earth state schema changes
- browser build can expose the new workspace independently
