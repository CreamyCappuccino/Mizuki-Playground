# v1.1 — Clarity and reproducible experiments

Feature track: **1.1.0-rc.1**. This does not close the physical iPhone Safari release gate, nor authorize site deployment. Earth-first: no other planets or new climate model.

## Implemented

- Optional workbench in the scrollable controls, not another crowded header toolbar. Seven bilingual questions prepare complete scientific settings, with an observation prompt. Fast/Slow heat storage presets are sequential experiments; A/B continues to differ only in tilt.
- Versioned, human-readable URL fragment and portable settings JSON. Shared scientific state includes both tilts, model day/rotation, selected coordinates, layer, model, heat storage, graph selection, Earth reference, guides, speed and close-up/orbit mode. Camera pose, playback, locale, fonts, quality, accounts and calculated thermal arrays are excluded.
- Explicit pause on successful restoration, useful view framing, one-step Undo. State is validated before any scientific field changes. The optional comparison module is awaited; newer user actions/hash changes cancel stale restoration. Existing worker request ordering remains intact.
- Copy fallback shows a selectable link when clipboard permission is missing. The copied link is a frozen snapshot and is marked stale when settings change. Localhost limitations are explained. Save/load files require no public app host or remote storage.
- Existing distinct pin/target science markers remain. No astronomical or climate equations were modified.

## Verification scope

Unit tests cover all schema fields, defaults, fractional days, malformed/large input, duplicates, unknown versions, coordinate pairing, safe unknown keys, preset integrity and real solar-noon geometry. Browser coverage checks undo, Japanese/large URL restoration, malformed updates, export/import, clipboard fallback, cancellation of stale imports and phone layout. Full Chromium and selected macOS WebKit suites remain mandatory at the same HEAD.

Runtime dependencies and lock graph are unchanged (only the package version field changes). No new external assets, network services, geolocation or automatic sharing.

Local browser execution may be unavailable under the development container's administration policy; GitHub Actions is the authority for Chromium/WebKit execution. Artifact screenshots are inspected, not assumed to imply real-device Safari acceptance.
