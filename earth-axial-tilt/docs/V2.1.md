# v2.1 — Mars astronomy-first

## Question

Earth and Mars have fairly similar obliquity, but do they receive seasons in the same way?

v2.1 adds Mars as the first non-Earth `PlanetDefinition` and compares it with Earth at a common seasonal longitude `Ls`.

## Mars definition

The implementation uses a fixed educational definition:

- semimajor axis: 1.523679 au
- eccentricity: 0.0934
- perihelion season: Ls 251°
- orbital period: 686.98 Earth mean-solar days
- obliquity: 25.19°
- sidereal rotation: 24.6229 h
- mean solar day: 24.6597 h
- prograde rotation

These are fixed model constants, not a dated ephemeris.

## Workspace

`planet-lab.html` provides Earth/Mars World A and World B selection with shared:

- seasonal longitude Ls
- latitude
- bilingual English/Japanese presentation
- optional Large text
- versioned share URL

Each world reports:

- Sun distance
- top-of-atmosphere ray-normal solar flux
- subsolar latitude
- daylight duration in that world's solar-day hours
- orbital-year length
- elapsed time since northern spring
- orbital speed relative to a circular orbit with the same semimajor axis

The comparison is **season-angle aligned**, not date aligned. Same Ls does not mean equal elapsed time or equal fraction of an orbit.

## Climate policy

Mars temperature is intentionally unavailable in v2.1.

Earth v1.x climate workspaces remain valid for Earth, but their EBM coefficients are not copied to Mars. The UI exposes this as an explicit capability difference rather than returning a fabricated temperature.

## Scientific limits

This is a two-body Kepler astronomy teaching model. It does not model:

- a current astronomical epoch
- orbital precession through geological time
- Mars atmosphere, dust, surface thermal inertia or weather
- habitability
- a Mars climate forecast

## Acceptance target

Earth and Mars can be compared using the same astronomy interface, Earth legacy regressions remain stable, and Mars never receives an Earth temperature result.
